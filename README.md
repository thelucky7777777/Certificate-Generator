# 燙金感謝狀製作工具 (Gold Foil Certificate Generator)

專為商務參訪、企業感謝與日式禮儀設計的線上實體燙金感謝狀排版與外框下載工具。
支援日式正統直書（縦書き）與現代標準橫書（横書き），並可一鍵匯出高解析度 PNG 與供雷射雕刻／燙金開模使用的 SVG 向量外框。

## ✨ 主要功能
- **雙向正統排版**：支援「日式傳統直書（右起無標點空格版）」與「現代標準橫書」。
- **多款燙金向量外框**：內建鳳凰雲紋、歐式雙線、唐草祥雲、巴洛克宮廷、日式龜甲等外框，支援匯出純向量 `.svg` 檔。
- **實體材質模擬**：提供和紙典藏、胡桃木銘牌、水晶壓克力三種背景預覽。
- **字級與間距微調**：支援即時調整內文字級、標題大小、行距，並具備防跑版與字數上限提示。
- **高解析度匯出**：一鍵下載 300 DPI 級別的 PNG 預覽圖檔或直接列印成 PDF。
